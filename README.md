# MES Alert – Privacy Policy

⚠️ **Tento repozitář není omylem prázdný.** Slouží výhradně k hostování veřejné stránky se zásadami ochrany osobních údajů (`privacy-policy.html`) pro Android aplikaci **MES Letoplast**.

## K čemu tento repozitář slouží

Google Play vyžaduje, aby každá aplikace měla veřejně dostupnou URL adresu se zásadami ochrany osobních údajů. Tento repozitář obsahuje pouze soubor `privacy-policy.html`, který je zveřejněný (typicky přes GitHub Pages) a jeho odkaz je zadaný v nastavení aplikace v Google Play Console.

- **Aplikace:** MES Letoplast (`sk.mio.mesalert`)
- **Google Play:** https://play.google.com/store/apps/details?id=sk.mio.mesalert&hl=sk
- **Účel repozitáře:** hostování jediné veřejné stránky – zásad ochrany osobních údajů

## Obsah repozitáře

```
.
├── privacy-policy.html   # Veřejná stránka se zásadami ochrany osobních údajů
└── README.md             # Tento soubor
```

Žádný jiný kód, konfigurace ani zdrojové soubory se zde záměrně nenachází – repozitář je určen jen pro tento jeden účel.

## Proč tento repozitář nemazat

Pokud bude tento repozitář smazán nebo se změní jeho veřejná URL adresa, přestane fungovat odkaz na zásady ochrany osobních údajů zadaný v Google Play Console. To může vést k tomu, že Google aplikaci **MES Letoplast pozastaví nebo odstraní z obchodu Play**, dokud nebude platná URL adresa znovu nastavena.

## Úprava obsahu

Při jakékoli změně `privacy-policy.html` je potřeba zkontrolovat, že:

1. Stránka je stále dostupná na stejné veřejné URL adrese (např. přes GitHub Pages).
2. Odkaz v Google Play Console odpovídá aktuální adrese.
3. Obsah stránky odpovídá aktuálnímu zpracování dat v aplikaci.
